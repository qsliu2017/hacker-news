# What-the-Fun dot

My personal web app for reading Hacker News and other RSS feed, in a simple way.

## Features

- **Keyboard Navigation**: Navigate through stories and comments using arrow keys
- **Serverless**: Fetch and cache content only in browser
- **SFW**: Suitable for work, no fancy UI, looks like you're working

## Getting Started

### Prerequisites

- Bun

### Run

```bash
bun dev
```
